# Core AI Solutions

Production website for Core AI Solutions, an engineering house in Lagos building software, AI, and payment infrastructure.

## Stack

- Next.js 16 (App Router)
- React 19
- Tailwind CSS 4
- TypeScript

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production

```bash
npm run build
npm start
```
